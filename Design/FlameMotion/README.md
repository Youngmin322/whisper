# 불꽃 걸음 참고 영상

`reference.mp4`는 홈 화면 불꽃 걸음의 형태와 리듬을 정한 사용자 제공 영상이다.

- 한 걸음은 약 0.66초이며, 영상의 첫 16프레임(24fps)을 사용한다.
- `FlameStepOuter00...15`, `FlameStepInner00...15`는 영상에서 바깥 불꽃과 안쪽 불꽃의 윤곽을 분리한 투명 마스크다.
- 홈 화면은 마스크에 각 감정의 기존 색을 입히고 원래 표정 SVG를 겹친다. 왼쪽 이동은 같은 프레임을 좌우 반전한다.
- `FlameHopMotion`은 세네 걸음을 이어 이동하고 잠깐 멈춘다. 움직임 줄이기가 켜지면 첫 프레임으로 고정한다.

이 영상은 디자인 참고용이며 앱 번들에는 포함하지 않는다.
