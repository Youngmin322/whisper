# 감정별 불꽃 움직임

여섯 승인 캐릭터는 각각 다른 움직임을 가진다. 기존 `reference.mp4`와 `FlameStepOuter/Inner00...15`는 이전 기쁨 불꽃의 동작 참고 자료로 보존한다. 현재 앱의 감정별 동작을 그 프레임으로 렌더링하지 않는다.

| 감정 | 홈 화면의 움직임 |
| --- | --- |
| 기쁨 | 기존 16프레임 자세로 가볍게 1~2걸음 총총 뛰고 2.7~12초 랜덤 휴식 |
| 평온 | 낮고 느린 부유와 작은 흔들림, 3.6~16초 랜덤 휴식 |
| 불안 | 먼저 멈칫한 뒤 작은 이동과 끝의 떨림, 3.8~17초 랜덤 휴식 |
| 우울 | 낮고 무거운 한 걸음, 5~22초 랜덤 휴식 |
| 분노 | 빠른 출발, 날카로운 기울임, 강한 박차, 2.9~13초 랜덤 휴식 |
| 슬픔 | 천천히 이동하고 끝이 뒤늦게 따라옴, 4~18초 랜덤 휴식 |

기쁨은 커밋된 `FlameStepOuter/Inner00...15`에서 추출한 자세 변화량과 기존의 0.66초 기본 리듬, 5.4pt 도약, 3.5pt 박차, 얼굴 회전·축소 값을 사용한다. 개체마다 템포에 작은 차이가 있지만 도약 강도는 원래 값을 그대로 사용한다. 이동할 때 승인 기쁨 PNG의 몸과 얼굴 레이어를 분리해 몸에만 기준 자세를 적용하고, 얼굴은 원본처럼 강체 회전·균일 축소한다. 쉬는 동안에는 분리 레이어나 변형을 사용하지 않고 승인된 `EmotionFlameJoy` 원본 PNG를 그대로 표시한다.

기쁨의 시작 구간에서는 원본에서 기준 자세로 부드럽게 이어지고, 마지막 13~15프레임 구간에서는 변형을 줄여 착지 전에 원본 형태로 돌아온다. 마지막 이동 자세에서 정지 PNG로 갑자기 교체되어 반전처럼 보이는 전환을 방지한다. 이동 방향은 착지·휴식 동안 유지하며, 다음 이동이 실제로 시작할 때만 새 방향을 적용한다. 중간 도약 자세와 이동 거리·속도·랜덤 휴식 일정은 유지한다.

`FlameMotionProfile`에서 감정별 리듬·한 걸음 거리·도약·휴식·끝 변형을 정의한다. `FlameFieldMotion`은 각 UUID에 고유한 시작 위치, 대기 시간과 이동 회차를 유지한다. 이동할 때마다 방향·거리·걸음 수·템포·다음 휴식 시간이 달라진다. 각자의 일정은 다른 불꽃의 개수나 이동 상태에 영향을 받지 않으며, 여러 불꽃이 동시에 움직일 수 있다. 휴식 길이는 매 이동 뒤 감정별 기본값의 0.45~2배 범위에서 독립적으로 뽑는다.

새로 저장되거나 필드에 추가된 불꽃은 즉시 첫 동작을 시작한다. 처음 불러온 기존 기록은 0.25~4초 사이의 서로 다른 시점에 움직이기 시작한다. 작성 화면이 떠 있는 동안은 일정을 멈춰 새 불꽃의 첫 동작이 홈으로 돌아오기 전에 끝나지 않게 한다. 화면을 다시 그릴 때는 UUID와 이동 회차를 기준으로 한 랜덤 값을 재사용하므로 경로나 리듬이 갑자기 바뀌지 않는다.

`FlameHopMotion`은 짧은 직선 이동과 감정별 진행 곡선, 착지 먼지와 그림자를 계산한다. 휴식을 늘려도 이동 중 속도가 빨라지지 않는다. 쉬는 동안 위치는 고정되고, 기쁨을 제외한 감정의 끝만 4.8~6.4초 주기로 아주 약하게 일렁인다. 기쁨의 정지 형태는 일렁임 없이 원본을 유지한다. `FlameBodyMotion`과 `FlameBodyWarp.metal`은 불꽃 끝과 바닥 쪽만 변형한다. 움직임 줄이기에서는 위치와 그림을 모두 정지한다. 화면을 떠나거나 앱이 비활성화되거나 병에 담을 때는 현재 포즈와 일정을 동결하고, 돌아오면 같은 위치에서 이어간다.

승인 PNG는 `Design/EmotionFlames/Approved/`에서 가져온 그대로 사용한다. `FlameMotionPreview`는 Debug 앱 실행 인자 `--flame-motion-preview`로 열 수 있으며 실제 홈 필드에서 1·3·6·10개의 감정 불꽃을 검토한다. 같은 감정끼리 비교, 움직임 줄이기, 불꽃 선택과 병에 담기 전환을 확인할 수 있다. 검토 기록은 저장하지 않는다. `emotion-motion-preview.mp4`는 이번 휴식·개별 이동 조정 전의 감정별 동작 참고 영상이다.

앱 화면으로 검증할 때는 현재 Xcode에서 열어 둔 체크아웃을 다시 빌드한다. 같은 브랜치의 다른 복사본을 수정해도 실행 중인 앱에는 자동으로 반영되지 않는다.

`reference-rig.json`, `tools/extract_reference_rig.py`, `reference-gait-comparison.*`, `app-common-gait.*`는 전체 PNG를 왜곡했던 이전 시도와 비교를 위한 과거 자료다. 현재 렌더러는 사용하지 않는다.
