# 사진을 붙인 다이어리 UI

2026-10-03 사용자와 시안을 비교해 합의한 방향.

## 화면의 역할

- 순간 남기기는 글 속에 사진을 붙여 한 번의 기억을 작성한다.
- 기록 상세는 작성한 글과 사진을 같은 배치로 다시 읽는다.
- 나의 하루는 시간순으로 모인 순간에서 시작해 사용자가 자신의 문장으로 다듬는 한 편의 일기다.

## 공통 표현

따뜻한 종이색과 읽기 쉬운 본문을 사용한다. 손글씨는 날짜와 제목에 집중한다. 사진은 얇은 종이 테두리, 작은 테이프, 가벼운 기울기로 종이에 붙인 느낌을 준다. 사진의 전체 내용은 확대해 볼 수 있어야 한다.

글과 사진은 같은 페이지의 흐름 안에 놓인다. 사진이 없는 기록도 자연스럽게 읽혀야 한다. 사진 앞뒤의 문장을 모두 편집할 수 있고, 키보드가 열렸을 때도 글과 사진의 연결을 유지한다.

## 나의 하루

날짜와 제목 아래 문단과 사진이 한 편의 글로 이어진다. 본문에는 순간별 시간 헤더, 반복 감정 불꽃, 세로 연결선, 별도 회고 섹션을 두지 않는다. 처음 남긴 순간들은 하단에서 필요할 때 펼쳐본다.

초안은 원문 그대로 시작한다. 앱이 사용자의 문장을 자동으로 다시 쓰지 않는다. 일기에서 문장과 사진 배치를 다듬어도 원본 순간은 바뀌지 않는다. 저장한 일기를 다시 수정해도 편집한 내용과 사진 위치를 보존한다.

## 구현에서 지킬 점

- 기존 기록과 저장한 초안을 읽을 수 있게 새 저장 필드는 기본값과 호환 가능한 디코딩을 제공한다.
- 사진을 제외한 검색·본문 문자열과 사진을 포함한 문서 배치를 함께 보존한다.
- 일기에 연결된 원본이 삭제되어도 다른 원본의 사진을 엉뚱한 위치에 연결하지 않는다.
- 기존 저장 실패, 임시 저장, 감정 선택, 사진 로딩 동작을 유지한다.
- 기능 단위로 검증하고 중간 커밋을 남긴다.
