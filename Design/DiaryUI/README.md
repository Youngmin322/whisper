# 다이어리 UI 구현 검증

2026-10-03, iPhone 17 / iOS 27 시뮬레이터에서 실제 SwiftUI 화면을 캡처했다. 사진 영역에는 테스트용 풍경 일러스트를 사용했고 개인 기록은 사용하지 않았다.

- `diary-moment-editor.png`: 순간 남기기. 본문 안의 사진, 사진 앞뒤 문장, 첨부 메뉴.
- `diary-record.png`: 남긴 순간 읽기. 작성한 사진 위치와 같은 종이 프레임.
- `diary-day-editor.png`: 나의 하루 편집. 한 편의 글과 사진, 대표 감정 하나, 하단의 접힌 원본 목록.
- `diary-day.png`: 저장한 일기 읽기. 편집한 글과 사진 배치 유지.

## 검증

`Whisper` 스킴의 전체 테스트 140개(25개 suite)가 통과했다. 테스트 실행으로 시뮬레이터 앱 빌드도 확인했다.

사진 앞뒤 입력·사진 삭제·여러 사진의 순서·사진 첨부 복사와 복원·확대 후 스크롤 영역, 순간/일기의 임시 저장과 재실행 후 복원, 원본 삭제 후 일기 사진 보존, 기존 V6 저장소의 V7 마이그레이션을 검증했다. 기존 작은 화면·큰 글씨·키보드 리사이즈·저장 실패 회귀 테스트도 통과했다.

`DiaryTextViewTests`에서 이 캡처를 다시 만들 수 있다. 각 테스트 실행 로그에 임시 PNG 경로가 출력된다.
