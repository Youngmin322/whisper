# iPad 홈 논의안 · 오늘의 불꽃

2026-10-07. 오늘 남긴 미보관 순간을 표시하는 iPad 홈 한 화면의 논의안입니다.

사용자가 원한 것은 불꽃을 한곳으로 모으는 배치가 아니라, 각자 움직이면서도 화면 전체까지 퍼지지 않도록 활동 범위를 제한하는 것입니다. 좌우에 여백을 두고 날짜 아래부터 하단 버튼 위까지 넓게 잡는 방향에 동의했습니다.

- Figma: `Whisper` → `v2.0 · 완료 / 작업 중` → `41 논의안 · iPad 홈 · 오늘의 불꽃`
- 프레임: `10609:2000`, 1194 × 834
- 링크: https://www.figma.com/design/dBVQ07i18D0BAlhU4qreuX/Whisper?node-id=10609-2000
- 활동 범위: x=127, y=172, 940 × 484. 좌우 127pt 여백, 날짜 툴바 아래 44pt, 하단 동작 영역 위 48pt.
- 불꽃은 각자의 기존 배회 움직임을 유지하며 이 영역 안에서 움직입니다. 중앙으로 끌리는 규칙은 없습니다. 불꽃 전체가 범위 안에 머무르도록 합니다.
- PNG의 불꽃 위치는 움직임 중 한 장면의 예시이며 고정 배치가 아닙니다.
- `Whisper-iPad-home-activity-bounds.png`: 활동 범위를 보여주는 설명용 점선 포함.
- `Whisper-iPad-home-activity.png`: 점선 없는 실제 화면 시안.
- Figma 점선 가이드 `10609:2043`는 기본적으로 숨겨져 있으며 제품 화면에 표시하지 않습니다.
- 기존 감정 불꽃 컴포넌트·BottleLineIcon·교보 손글씨 2019·Noto Sans KR·앱 색상 변수를 재사용했습니다.
- 설정·더하기·상태 표시는 AppKit이 렌더링한 실제 SF Symbols를 개별 이미지 노드로 사용했습니다. 로컬 플러그인에는 커넥터의 SF Symbol 문자 도우미가 없습니다.
- 글자는 편집 가능한 텍스트, 불꽃은 컴포넌트 인스턴스, 병은 벡터입니다. 레이어·활동 범위·움직임 의도는 `Whisper-iPad-home-activity-state.json`에 기록했습니다.

Figma 데스크톱에 동기화 대기 안내가 있어 원격 반영은 확인하지 못했습니다. 최신 로컬 사본 `Whisper-iPad-home-latest.fig`는 버튼과 무채색 비교안을 포함한 파일 전체입니다. `Whisper-iPad-home-activity-20261007.fig`는 활동 범위를 수정했을 때의 사본입니다. 이전 `discussion` 이름의 PNG·JSON·FIG는 중앙에 모으는 것으로 잘못 해석했던 첫 시안의 기록입니다. 용량이 큰 `.fig` 사본은 로컬에 보관하고 Git 커밋에는 포함하지 않습니다.

앱 소스는 변경하지 않았으며, 다른 화면도 아직 확정하지 않았습니다.

버튼과 색감 논의 (2026-10-07):

- 사용자는 iPad를 주로 책상이나 거치대에 두고 사용합니다.
- 홈의 두 동작은 **아이콘 + 글자: 병에 담기 / 순간 남기기**로 표시하기로 했습니다.
- 하단 오른쪽 배치와 `순간 남기기`를 주된 동작으로 강조하는 것은 비교를 위한 제안이며, 최종 배치는 아직 확정하지 않았습니다.
- 두 버튼은 높이 48pt, 간격 12pt, 오른쪽 여백 32pt입니다. 기존 병 자산과 실제 SF Symbols를 사용합니다.
- `Whisper-iPad-home-buttons.png`는 이름을 붙인 뒤의 기존 크림색·갈색·주황색 시안입니다. 사용자가 전체 색감을 지적해 최종안으로 사용하지 않습니다.
- `Whisper-iPad-home-neutral.png`는 흰 배경, 무채색 글자·버튼, 기존 감정 불꽃을 유지한 **색감 비교안**입니다. 날짜의 베이지색 밑줄과 버튼 그림자를 숨기거나 제거했습니다.
- 무채색 방향과 불꽃 색 변경 범위는 사용자 검토 중입니다. 기존 불꽃 색을 유지한 것은 이번 비교안의 가정이며 최종 색상 결정이 아닙니다.
- 기존 색상 변수의 값은 변경하지 않고, 이 홈 프레임의 바인딩만 교체했습니다. 새 색상 변수나 재사용 컴포넌트는 만들지 않았습니다.
- 색상 변수는 흰색 `1388:10249`, 잉크색 `477:7245`, 보조 글자색 `477:7248`, 강조 위 글자색 `1388:10246`입니다. 실제 네이티브 구현에서는 적절한 시스템 배경·글자색 API와 버튼 스타일을 선택해야 합니다. 이 PNG는 라이트 모드의 디자인 비교용이며 네이티브 렌더링 검증 결과가 아닙니다.
- `Whisper-iPad-home-buttons-state.json` 및 `Whisper-iPad-home-neutral-state.json`에 변경 노드·합의 내용·제안 내용을 구분해 기록했습니다.
- 작성 화면의 상단 취소·저장 위치 유지, 초안 삭제의 더보기 메뉴 이동은 후속 논의 제안입니다. 아직 해당 화면을 수정하지 않았습니다.

현재 재현 순서는 `home-assets.js` + `build-home.js` + `home-launch.js`로 첫 프레임 생성 → `revise-activity-area.js` → `home-assets.js` + `revise-home-buttons.js` → `home-assets.js` + `revise-home-colors.js`입니다. 수정 스크립트는 상태 JSON에 있는 기존 프레임 ID를 기준으로 동작합니다.

레퍼런스 확인 후 요청한 배치 시안:

- 사용자가 제안된 배치를 Figma 시안으로 만들어 보여달라고 요청했습니다. `Whisper-iPad-home-actions.png`가 해당 결과이며, 기존 오른쪽 배치는 `neutral.png`에 남아 있습니다.
- 설정은 왼쪽 위, 날짜는 위쪽 중앙, 보관함은 오른쪽 위에 유지합니다.
- `병에 담기`는 날짜 아래의 아이콘 + 글자 보조 버튼입니다. 배경 채움·테두리·그림자를 제거했으며 누르는 영역은 101 × 44pt, 위치는 x=546.5, y=86입니다.
- `순간 남기기`는 하단 중앙의 아이콘 + 글자 강조 버튼입니다. 크기는 136 × 48pt, 위치는 x=529, y=716입니다.
- 활동 범위 x=127, y=172, 940 × 484는 이전 합의 그대로입니다. 컨트롤은 활동 범위와 겹치지 않습니다.
- 날짜·병에 담기 그룹은 오토레이아웃으로 구성했습니다. 검증 기록은 `Whisper-iPad-home-actions-state.json`입니다.
- 버튼의 역할·위치를 확인하는 정적 디자인입니다. 실제 iPadOS 시스템 버튼의 눌림·유리 재질·접근성·창 크기 대응은 네이티브 구현에서 검증할 대상이며, 앱 코드는 수정하지 않았습니다.
- 이 배치는 검토를 요청한 시안이며 최종 승인된 디자인은 아닙니다.

최신 배치를 재현하려면 무채색 비교안을 만든 뒤 `revise-home-action-placement.js`를 실행합니다.

버튼 인지성 수정:

- 날짜 아래의 `병에 담기`가 설명처럼 보일 수 있다는 논의 후, 사용자가 얇은 무채색 테두리를 두른 둥근 버튼 시안을 요청했습니다.
- `Whisper-iPad-home-outlined.png`는 해당 수정안입니다. 위치와 크기 101 × 44pt는 유지하고, 모서리 반경 22pt와 안쪽 1pt 테두리를 적용했습니다.
- 테두리는 기존 보조 글자색 변수 `477:7248`에 불투명도 60%를 적용합니다. 새 색상 변수는 만들지 않았습니다.
- 하단 기록 버튼과 불꽃 활동 범위·개별 위치는 유지했습니다. `Whisper-iPad-home-outlined-state.json`에 변경 노드와 검증 결과를 기록했습니다.
- 최신 배치 스크립트 실행 후 `revise-collection-outline.js`로 재현합니다. `Whisper-iPad-home-latest.fig` 로컬 사본에도 반영합니다.
- 앱 소스는 수정하지 않았으며 실제 네이티브 버튼 렌더링은 아직 검증하지 않았습니다.

하단 두 버튼 비교안:

- 사용자는 날짜 아래의 테두리 버튼도 버튼으로 느껴지지 않는다고 피드백했습니다. 두 동작을 하단 중앙에 나란히 놓고 채워진 둥근 사각형으로 만드는 비교안을 요청했습니다.
- `Whisper-iPad-home-bottom-pair.png`는 새 배치입니다. 왼쪽 `병에 담기`는 옅은 회색, 오른쪽 `순간 남기기`는 기존 잉크색으로 채웠습니다.
- 두 버튼은 각각 148 × 48pt, 모서리 반경 12pt, 간격 12pt입니다. 글자는 같은 Noto Sans KR Medium 16pt이며 원래 병 아이콘과 SF Symbol 더하기를 사용합니다.
- 회색은 기존 잉크 변수 `477:7245`에 불투명도 10%를 적용했습니다. 새 변수·컴포넌트는 만들지 않았습니다.
- 날짜 아래에는 버튼이 남아 있지 않습니다. 활동 범위 x=127, y=172, 940 × 484 및 불꽃 5개의 위치를 유지했습니다.
- 검증 기록은 `Whisper-iPad-home-bottom-pair-state.json`, 재현 스크립트는 `revise-bottom-action-pair.js`입니다. 이전 날짜 아래 배치 시안은 별도 PNG·JSON에 보존합니다.
- 앱 소스는 수정하지 않은 검토용 디자인입니다. 실제 iPadOS 버튼 렌더링은 아직 검증하지 않았습니다.

Apple 공식 UI 키트 버튼:

- 사용자가 직접 그린 버튼 대신 iPadOS 에셋을 가져와 수정하도록 요청했습니다. Figma 에셋 패널에 기본 제공되는 Apple의 `iOS and iPadOS 27` → `Buttons` → `Button - Content Area`를 사용했습니다.
- 공식 출처: https://developer.apple.com/design/resources/ 및 https://www.figma.com/community/file/1651309003795292092/ios-and-ipados-27
- `Whisper-iPad-home-apple-buttons.png`가 현재 시안입니다. 이전 커스텀 버튼은 숨겨 보존하고 원격 컴포넌트 연결을 유지한 인스턴스로 교체했습니다. 컴포넌트를 분리하거나 버튼의 모서리·패딩·폰트·색을 직접 재정의하지 않았습니다.
- `병에 담기`는 Large / Bordered / Title only, `순간 남기기`는 Large / Bordered - Prominent / Title and Icon입니다. Label과 Symbol 속성만 앱 문구 및 `+`로 변경했습니다. 병 그림은 하단 버튼에서 제거했습니다.
- 키트 기본 색상은 회색 배경·파란 글자의 보조 버튼과 파란 배경·흰 글자의 강조 버튼입니다. Large의 높이 50pt와 SF Pro 17pt를 유지했습니다. 글자 길이에 따라 너비는 각각 106pt와 136pt이며, 그룹은 간격 12pt로 하단 중앙에 놓았습니다.
- 활성 인스턴스는 `10619:2329`와 `10619:2326`입니다. 출처 컴포넌트 키·변형 속성·검증 결과는 `Whisper-iPad-home-apple-buttons-state.json`에 기록했습니다.
- 활동 범위와 불꽃 위치를 유지했습니다. `Whisper-iPad-home-latest.fig`는 최신 로컬 사본입니다. Figma 클라우드 동기화는 대기 중입니다.
- 재현하려면 에셋 패널에서 해당 Apple 버튼 인스턴스를 가져온 뒤 `revise-apple-kit-buttons.js`를 실행합니다. 현재 파일에서는 기존 인스턴스를 재사용합니다.
- Figma 공식 키트에 기반한 시안이며 실제 SwiftUI 런타임 렌더링 결과는 아닙니다. 앱 소스는 수정하지 않았습니다.

Liquid Glass와 앱 색상 수정 준비안 (적용 미확인):

- 사용자는 앱 색상에 맞추기를 요청했으며 Liquid Glass를 생각하고 있었다고 밝혔습니다. 하단에 떠 있는 조작부라는 맥락에서 Liquid Glass를 추천합니다.
- Apple 공식 `Button - Liquid Glass - Text` 인스턴스 `10619:2457`를 에셋 패널에서 가져왔습니다. 목표는 `병에 담기` Large / Glass, `순간 남기기` Large / Glass Prominent입니다.
- 준비한 스크립트는 기록 버튼의 공식 Tint 레이어를 기존 `whisperAccent` 변수 `1388:10242` (`#F4523B`)에, 보조 버튼 글자를 `whisperTextPrimary` 변수 `1388:10244` (`#3E3530`)에 연결합니다. 글로벌 변수 값은 변경하지 않습니다.
- 공식 재질·그림자·원격 컴포넌트 연결을 유지하고, 불꽃 활동 범위와 위치가 보존됐는지 확인한 뒤 PNG와 검증 JSON을 내보내도록 작성했습니다.
- `revise-liquid-glass-buttons.js`의 JavaScript 구문 검사만 통과했습니다. Figma 창 제어가 응답하지 않고, Figma MCP도 Starter 사용 한도에 도달해 적용·색상 바인딩·재질 보존·PNG 내보내기를 확인하지 못했습니다. Liquid Glass PNG·검증 JSON은 아직 생성되지 않았습니다.
- 확인된 최신 비교안은 여전히 `Whisper-iPad-home-apple-buttons.png`입니다. `Whisper-iPad-home-latest.fig`도 이전 Content Area 버튼 버전입니다. 앱 소스는 수정하지 않았습니다.
- 참고: Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) — 콘텐츠 위의 조작 계층에 사용하고, 색은 주된 동작을 강조하는 데 제한합니다.

탐색 흐름 결정:

- 사용자가 중요하게 보는 흐름은 **홈에서 기록하다가 필요할 때 보관함 열기**입니다.
- 이번 디자인에서는 탭바와 전역 사이드바를 추가하지 않습니다. 기존 홈의 보관함 버튼을 진입점으로 유지합니다.
- 보관함에서는 상단의 돌아가기 조작으로 홈에 복귀하는 구성을 제안합니다. 홈의 오늘 기록과 작성 상태는 유지해야 합니다.
- 검색은 기존 앱처럼 보관함 안에서 접근하고, 설정은 홈의 작은 설정 버튼으로 접근합니다.
- 사용자가 지적한 선택 후 탐색 영역의 자동 접힘은 원치 않는 동작입니다. 이번 안은 탭·사이드바를 사용하지 않으며, 보관함에 들어간 뒤에도 돌아가기 조작이 보이도록 설계합니다.
- 보관함에서 날짜를 선택한 뒤의 일기 읽기 배치는 다음 논의 대상입니다. 위 결정은 디자인 방향이며, 현재 앱의 탭 구조를 이미 바꿨다는 의미는 아닙니다.

`home-assets.js` + `build-home.js` + `home-launch.js`는 해당 파일의 기존 컴포넌트·변수가 있을 때 홈을 생성하는 코드입니다. `revise-activity-area.js`는 기존 홈 프레임의 활동 범위를 수정한 코드이며, 검증·PNG 내보내기·설명용 가이드 표시 기능을 포함합니다.
