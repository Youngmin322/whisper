## 초기 검증 이후 UI 보정

사용자 요청에 따라 주요 버튼·저장 버튼은 기존 강조색 `#F4523B`로 복원했습니다. 위 #36의 대비 수치는 초기 수정 당시 기록이며 현재 버튼에는 적용되지 않습니다. 남긴 순간 수정 화면의 중첩된 `닫기` 버튼도 제거하고 기본 뒤로 가기를 사용합니다. 화면 이탈 시 수정 초안 보관은 유지합니다. 판단 근거는 [기술 의사결정의 UI 보정](Pre-Release-Decisions-2026-10-04.md#사용자-피드백에-따른-ui-보정)에 기록했습니다.

보정 후 iOS 27.0의 `Whisper Flame Check` 시뮬레이터에서 앱 빌드와 작성 화면·순간 수정 초안 관련 **8개 테스트 / 2개 suite**가 통과했습니다. 화면 이탈 후 재개와 저장 전 원본 유지가 포함됩니다. 로그: `/private/tmp/whisper-ui-corrections-tests.log`. 아래 전체 테스트·아카이브 결과는 초기 수정 기준의 기록입니다.

## 검증 결과

- Xcode 27.0, iPhone 18 Pro, iOS 27.0: 전체 **151개 테스트 / 28개 suite 통과**.
- `git archive`로 커밋된 파일만 추출한 체크아웃, 외부 형제 패키지 없음: iPhone SE 3세대, iOS 26.5에서 전체 **151개 테스트 / 28개 suite 통과**.
- 새 회귀 테스트: 삭제된 일기 초안의 재시작·사진 복원·날짜 충돌·원자적 실패 복구, 실제 V6 저장소의 원본 수정·삭제 후 사진 보존, 여러 순간 수정 초안의 분리·복원·실패 재시도 및 삭제된 원본 복구.
- 실제 iPhone SE 시뮬레이터 조작: 온보딩 → 감정 선택 → 키보드 본문 입력 → 앱 재시작·초안 재개 → 순간 저장 → 순간 수정 → 닫기·초안 재개 → 수정 저장 → 병에 담기 → 일기 저장 → 보관함에서 같은 본문 다시 읽기 완료. 저장 전 원본 본문 유지 및 저장 후 초안 제거 확인.
- 깨끗한 체크아웃에서 기기용 **Release 아카이브 생성 성공**(`CODE_SIGNING_ALLOWED=NO`). 앱 실행 파일, dSYM, 개인정보 매니페스트, 패키지 리소스 번들 포함 확인.
- SwiftData 과거 스키마의 모델 형태는 변경하지 않았습니다. 수정 초안은 기존 JSON payload에 선택 필드를 추가하며, 이전 초안의 복원도 테스트했습니다.

아카이브 확인 당시 버전은 `2.0.0 (1)`, 최소 OS는 `26.0`입니다. 이 아카이브는 서명 없는 빌드 검증용이며 업로드용이 아닙니다.
